## 开发这个脚本解决JAVDB官方的什么功能？

- **原本的页面陈旧** JAVDB官网简洁但多年不变样，信息量虽然足但是美观不足毫无沉浸感。
- **官方收藏夹功能太简陋** 只能单纯加入清单或者看过想看标记，不能针对性搜索、筛选、排序、做备注，列入JAVDB不能针对某女优统计搜索自己收藏她的哪些作品，无法标记收藏某些剧照截图，无法通过更精细更个性化的搜索条件寻找自己收藏的影片
- **官方数据错误或缺少** 用JAVDB最大的缺点就是官方虽然有订正功能，但是不经过官方审核的话是不会显示自己的订正数据的，并且官方很少处理数据订正。对于经常漏写女优、标签分类不准，强迫症可以借由这个功能避开官方的限制形成自己的本地数据管理且可以随时于上游核对订正
- **看片要到处记网址或搜索** 直接内置外部站点管理，一键检测和跳转优秀的外部网站，不必输入番号搜索。
- **自给自足，整治仓鼠症** 通过界面精细化重构+数据本地多元化修正与管理筛选+云端播放跳转三种最核心的功能设计思路让这个脚本形成依托JAVDB打造自己专属的流媒体影库，且不用像仓鼠症人士一样辛苦下片就只是为了看收藏到的海报墙的满足感，以及一些外挂小功能插件，可以随时解决很多个性化问题。
  
  最终，形成一个不改动官方原有账号数据，完全在你的浏览器本地搭建起一个**独立、安全、强大又好看的专属私人JAV媒体库**。

## 超丰富功能全景介绍

### 1. 影院级视效重构（三种质感随心切换）

- **三大视觉流派**：
  - **EMBY 经典**：沉稳高级的深色流媒体质感，完美EMBY经典体验。
  - **毛玻璃 (Glass)**：细腻优雅的亚克力通透质感，搭配动态背景虚化，柔和有层次。
  - **液态玻璃 (Liquid Glass)**：追求最新的"玻璃拟态"效果，边缘有真实的折射扭曲和高光。
- **丰富的海报陈列方式**：
  - **右侧裁切模式**：自动聚焦AV影片封面包装右侧图区域，让海报最好看的一面面向用户。
  - **完整大封面模式 / 融合模式**：展现原汁原味的整张海报，封面与环境背景柔和过渡，且可以互动卡片小图封面。
  - **Pinterest 式瀑布流**：打破死板方块，自适应高低海报，横向自然排列，排版具有冲击力。
  - **Steam 风格 3D 物理倾斜卡牌**：悬停在海报上时，卡片跟随鼠标发生立体倾斜高光流转，。
  - **悬停超清预览气泡**：鼠标停在封面上，无需点击进入页面，自动浮现超清大图气泡，还可自由调节弹出延迟与大小。

---

### 2. 超越官方限制的“本地私人媒体库”

- **自建独立本地数据库**：
  - 不依赖官方服务器，所有收藏记录、状态与备注安全保存在您的浏览器本地，断网也能飞速检索。
- **状态快捷标记与“个人评分”分离**：
  - 海报角落一键点亮【想看 / 已看】，还能直接打上 1~5 星。
  - **核心特色**：**您的个人打分与官方大众均分彻底分开！** 官方评 3 星但您很喜欢？直接点亮您的 5 星，不受大众均分影响。
- **个性化备注**：
  - JAVDB官方对影片做备注需要用看过功能，限制多，且只支持影片，本脚本的备注对于所有元素据都支持。
  - 可选择直接在封面底部展示醒目的**斜体橙色笔记便签**，找片一目了然。
- **多维智能筛选与排序**：
  - 可以在收藏夹中按女优、按片商、按导演、按分类标签极速筛选，也可按添加时间、上映日期、等随意排序。

---

### 3. 多源播放跳转与全网情报秒查

- **告别失效与卡顿，全网多源一键看**：
  - 如果您是官方会员，可直接在页面内免跳转播放官方片源。
  - 如果不是会员或需要更多线路，脚本自动在详情页提供**各大主流在线播放站点（如 MissAV 等）的快捷跳转按钮**。
  - 自动提取站点 LOGO 主色调，按钮精致美观。
  - **完全开放自由**：可以在设置里任意拖拽调整播放站点顺序，修改网址规则，甚至添加您自己的私藏播放站点。
- **各大番号数据库一键核对**：
  - 详情页番号后方自动陈列各大权威情报站（JAVBUS、JAVLibrary、FANZA、JAVtxt 等）小图标，点击即可直达对比磁链、查看更多网友评论。

### 4. 【预览画廊】存留自己最喜欢的剧照

- **告别一张小图猜整部片**：
  - 顶栏直接集成独立的**【预览画廊】**专区！
  - 脚本自动接入外部高清剧照源（javfree、javstore、blogjav 等），自动抓取作品全套官方超清剧照。
- **沉浸式画册体验**：
  - 支持高清大图瀑布流陈列；
  - 点击任意图片即刻唤醒**无损全屏灯箱**，支持鼠标滚轮缩放、键盘上下左右键切换图片，看剧照就如同翻阅精美纸质写真集。

### 5. 女优全方位情报档案

- **Gfriends 高清写真头像库替换**：
  - JAVDB官方自带头像通常质量不高，脚本自动对接 Gfriends 高清头像库（男女演员均支持）
  - 如果云端图库没有匹配到，会自动平滑保留官方头像。
- **女优个人信息与现役状态**：
  - 鼠标悬停在女优名字上，即刻获知女优的**年龄、出生日期、身高、三围**等官方信息。
  - 贴心标注**“现役 / 已退役”**，让您一眼了解演员最新动态。且可同时自定义这个演员备注。
- **一键红心收藏女优**：
  - 头像右上角附带心形标记为已经收藏的女优，信息卡片中可以把她加入收藏清单。

- **随心修补官方错漏**：

- **纠错管理后台**：
  - 设置中心专门开辟了“元数据纠错管理”表格，集中记录你所有修改过的作品，支持一键搜索。
- **一键比对云端自愈**：
  - 当日后官方数据库更新补全了该女优或更正了信息，只需在后台点击【一键检查自愈】，脚本会自动比对最新官方数据。若官方已正确收录（以用户写入的为准），将**自动清退本地冗余规则并完成合流**，永远保持数据库干净纯正！

### 开始使用

装好之后直接访问 JAVDB，页面不会自动变成新界面。第一次启动默认关闭的，需要在屏幕点击左下角的**粉色J圆形按钮**开启：

- **左键点击** —— 开启 / 关闭整个皮肤。关掉之后网站立刻恢复原样，随时可以再开。
- **右键点击** —— 在三种视觉风格之间循环切换。
- 鼠标悬停在按钮上，会显示当前风格和版本号。

## 功能详解

### 一、三种视觉风格

#### 顶部栏与左侧菜单

原来的 JAVDB 导航栏被换成了一条**通透的顶部栏**：左边是菜单按钮和 LOGO，右边是搜索和设置。顶部栏用的是"上深下透明"的渐变，页面内容可以从下面滚过去，不会像原来那样被一条实心色块挡住。

点击左上角菜单按钮，会从左侧滑出一个**抽屉式菜单**，里面放着：

- 类别、排行榜、演员、片商四个常用入口；
- 你原来账号里的全部菜单项（个人资料、我的清单、收藏的演员、通知中心、登出……），每一项都配了对应的图标。

#### 卡片动效

鼠标滑过任意一张作品海报时，卡片会**跟着鼠标轻微倾斜**，同时有一道光从卡片表面扫过——像在拿着一张有厚度的实体卡牌。这是全站统一的交互，在首页、收藏夹、榜单里都一样。

#### 界面净化

脚本会自动隐藏这些干扰内容（**只在皮肤开启时生效，关掉皮肤就恢复原样**）：

- 主页顶部的"最新网址"公告条；
- 页面里各类广告位和推广卡片；
- 原版页面底部的"关于 / 条款 / 隐私 / 广告投放"区块；
- 悬浮在右下角的下载按钮和右上角的跳转按钮；
- 原版那个占地方的老式搜索栏。

作品详情页是改动最大的地方。

### 四、我自己的收藏夹

**这是整个脚本最核心的功能。**

JAVDB 官方的"我的清单"只能看，不能搜、不能筛、不能排序、不能写笔记，作品多了之后基本没法用。脚本把整个清单**搬进你的浏览器本地**，建成一个真正的个人影库。

#### 怎么建起来

进收藏夹页面，点工具条上的 **"获取和整理收藏"**，里面有六个动作：

| 动作 | 说明 |
| --- | --- |
| **同步清单** | 先勾选要同步的清单，再拉取里面的作品。新增的清单可以只同步新增部分，不用全量重跑 |
| **同步想看 / 看過** | 从 JAVDB 的想看、看過专属页面快速同步标记状态，通常几分钟内完成 |
| **补全信息** | 只为库里还没补全的作品抓取详情（增量、不重复） |
| **刷新详情** | 强制重抓库内全部作品，跟进演员改名、信息更正等（耗时较长，可随时暂停） |
| **识别性别** | 逐个访问演员主页，标记出男优（识别一次永久生效） |
| **同步已收藏演员** | 同步你在 JAVDB 关注的女优，点亮头像上的小红心徽章 |

每一步都能**随时暂停、继续或取消**，进度条上实时显示"已完成 / 总数"和当前步骤。抓取速度可以自己调（并发 1 到 6，默认 3），怕被网站限制就调低一点。

脚本本身也很克制：一旦察觉网站开始限制访问（包括触发人机验证），会**自动停下来保护你的账号和 IP**并提示你稍后再试，而不是硬碰硬。

#### 平时几乎不用手动同步

脚本会**看着你在 JAVDB 上的操作**：当你在网站上把一部作品加入清单、移出清单，或者标记想看、看過时，脚本会**立刻把变化写进本地收藏夹**——不需要你再去点一次"同步"。

清单改了名字或数量这类小变化也会自动跟上，不会打断你正在做的事。就算你是在手机上完成的收藏，下次打开网页同步时或者手动进入某一影片，均会检测对比然后同步把它补进来。

#### 收藏夹里能做什么

| 功能 | 说明 |
| --- | --- |
| **搜索** | 按番号或标题实时搜索，**连你写的备注内容也能搜到** |
| **筛选** | 七个维度：演员、片商、系列、导演、类别、年份、金标。勾选即过滤 |
| **共演筛选** | 同时选中两位以上演员，只看他们**共同出演**的作品，候选会自动收敛 |
| **快捷开关** | 只想看、看过、只看金标、只看有备注、只看未补全、最近 7 / 30 / 90 天发行 |
| **排序** | 日期、评分、评价人数、番号、入库时间、浏览量、金标等级（金标按 TOP250 等级自动加权） |
| **清单范围** | 多个清单可以勾选叠加过滤 |
| **条件胶囊** | 每个已生效的条件都显示成一枚胶囊，点上面的 ✕ 就能单独去掉 |
| **显示大小** | 一条滑杆实时调整封面大小（180–560 像素），网格和瀑布流都跟着变 |
| **卡片扩展信息** | 比首页卡片多显示演员和片长，还能直接在卡片上看到你写的备注 |
| **状态保持** | 从收藏夹点进详情页再返回，筛选条件、排序和滚动位置全都还在 |

作品多了也不会卡：列表用的是**无限滚动**（滚到底自动加载下一批），大库照样秒开。

第一次打开还是一片空白时，页面会直接告诉你下一步该做什么——不会让你对着空屏发呆。

### 五、预览画廊

"预览画廊"是收藏夹的附属视图，专门用来**浏览作品的剧照和预览图**。

- 按作品分组，左边是封面，右边是这一部的所有预览图；
- 三种展示方式：**平铺**（一张挨一张）、**全量**（全部图片铺成瀑布流）、**收拢**（作品卡片堆叠，点开哪部就展开哪部的大图，其余的变暗让路）；
- 点开任意一张图片会进入**全屏灯箱**，可以左右翻页浏览，右上角一键关闭；
- 灯箱里可以**用滚轮缩放、拖动查看细节、双击放大**，也能直接按下 **"收藏此图"** 把好图留下来；
- 同样支持按番号和标题过滤，显示大小也能用滑杆统一调节。

> 💡 **怎么往画廊里存图？** 在任意作品详情页点开预览大图，点右上角的 **"收藏此图"**，这张图就会进入你的预览画廊。日积月累，画廊就成了你自己的剧照收藏库。

### 六、TOP250 与热播榜

#### 热播榜：打开就能看

热播榜**不需要登录**，打开即见，可以切日榜、周榜、月榜。每部作品显示排名、评分、日期，以及是否带中文字幕磁链。

#### TOP250：登录一次，永久使用

完整的 TOP250（250 部）需要一次身份验证。**用普通免费账号就行，不需要会员。**

- 登录窗口有两个选项：直接填 JAVDB 账号密码，或者粘贴一个现成的 Token；
- 凭证保存在你自己浏览器的本地，脚本不会发送到任何第三方；
- 验证一次之后，之后每次打开都是直接看。

#### 离线缓存

TOP250 支持 **"离线缓存全量 250 部"**：点一下把整份榜单存到本地，之后即使网络不好也能秒开浏览。缓存有失效时间，过期会自动更新。

#### 榜单里也能筛选

TOP250 面板里的 **"筛选"** 按钮，用的就是收藏夹那套高级筛选器：关键词、评分上限、荣誉、演员（含共演模式）、片商、系列、导演、类别、年份，一应俱全。名次前三的作品还有金银铜三色角标。

> 💡 如果你本来就登录着 JAVDB 会员账号，脚本会自动让路，不干扰你原本的会员权限。

### 八、备注与标记系统

#### 到处都能写笔记

- **作品级备注** —— 详情页番号旁边的 **"備註"** 按钮，写下任何想记的东西（比如"强推""待看""周末看"）；
- **演员 / 片商 / 系列级备注** —— 在对应的详情页点 **"备注"** 按钮，给这个人或这家公司写笔记。

写完的备注会在收藏夹里直接显示在卡片上（橙色斜体），也能用来搜索和筛选——**"只看有备注"** 开关一点，所有写过笔记的作品就都列出来了。

#### 悬停卡片

鼠标停在女优头像上，会浮出一张**信息卡片**，里面有：

- 女优姓名和现役 / 引退状态；

## 常见问题解答 (FAQ)

<details>
<summary><b>Q1：开启这个脚本后，会导致电脑或网页变卡吗？</b></summary>
<br/>
<b>完全不会。</b> 脚本经过极为严格的性能优化，所有数据库读取、图片抓取与模糊渲染都采用了轻量化异步处理机制，不占用主线程运算。即使您的媒体库收藏了数千部作品，依然能够秒开、秒翻页、丝滑流畅。
</details>

<details>
<summary><b>Q2：如果我想暂时换回官方原本的网页排版，该怎么操作？</b></summary>
<br/>
非常简单！脚本支持<b>双模式无缝共存</b>。点击右上角的齿轮图标打开设置中心，直接将最上方的【启用皮肤】开关关闭，整个网页会立刻毫秒级还原为官方原版样式；随时再次打开开关，又会立刻回到漂亮的影院模式。
</details>

<details>
<summary><b>Q3：我换了一台新电脑，或者重装了浏览器，收藏的数据怎么带走？</b></summary>
<br/>
您有两种极为简便的同步方式：
1. <b>使用云端备份（推荐）</b>：在旧电脑的设置中心里配置好坚果云（WebDAV）或 GitHub，点击【立即备份】；在新电脑上输入账号点击【恢复】即可秒级同步。
2. <b>使用文件导出</b>：在旧电脑的【数据管理】中点击【导出数据】，将下载得到的 JSON 文件发送到新电脑，点击【导入数据】即可一键恢复。
</details>

<details>
<summary><b>Q4：为什么有的番号没有外部播放按钮或者点开无法播放？</b></summary>
<br/>
外部播放按钮是根据各大公开资源站的规则自动匹配生成的。对于极其冷门、年代久远或尚未公开发行的极少数作品，外部站点可能暂未收录。您可以随时在设置中心的【外部网站】中自行添加更多第三方播放源，或者点击番号后面的 JAVBUS/JAVLib 图标去查询最新磁力链接。
</details>

<details>
<summary><b>Q5：把备份文件发给朋友分享，会泄露我的账号密码吗？</b></summary>
<br/>
<b>绝对不会，只要您关闭了凭证导出开关。</b> 脚本在【数据管理】和【云端备份】中均内置了<b>“备份时包含登录凭证与密钥”</b>的安全开关（默认处于关闭状态）。关闭状态下导出的备份文件会自动剔除所有登录令牌、个人密钥与敏感信息，您可以放心地将珍藏清单分享给同好。
</details>

## 常见问题

### 装完之后页面没变化？

1. 确认油猴扩展已经启用，脚本在管理面板里是"已启用"状态；
2. 确认你访问的确实是 JAVDB 网站（脚本只在 JAVDB 及官方镜像域名上生效，这是有意的保护措施，避免在别的网站误触发）；
3. 刷新一下页面（按 `Ctrl + Shift + R` 强制刷新）。

### 怎么关掉它？

点击左下角的粉色J字母圆形按钮，或者右键点它切风格。**关掉之后网站立刻恢复成你熟悉的原样，不会残留任何痕迹。**

### 会不会影响我原本的 JAVDB 账号和收藏？

不会。脚本只是读取网页上公开显示的信息，**不会修改你在 JAVDB 服务器上的任何数据**。会主动提交的操作是想看、看过、收藏女优——而且那本来就是你点按钮主动要求的。

会员账号更不用担心：脚本检测到你是会员时会自动让路，不干扰你原本的完整权限。

### 会不会被网站封号？

脚本刻意做了保护：

- 所有批量抓取都有**速度限制**和**随机间隔**；
- 一旦网站开始返回限制信号，**立刻自动停止**并提示你——宁可慢一点，不冒险；
- 抓取并发数可以自己调低。

正常使用完全不需要担心。

### 收藏夹同步很慢怎么办？

第一次同步确实需要时间（作品越多越久）。但：

- 之后都是**可以手动的增量更新**，只同步有变化的部分，几秒钟完成；
- 可以随时暂停、继续；
- 想要更快就把"并发"滑块调大（最高 6），网络好时可以明显提速。

### 换电脑了，数据怎么办？

用 **云端备份**（WebDAV 或 Git）或**导出 JSON 文件**，在新电脑上导入即可，影片、清单、备注、配置全都在。

### 数据存在哪里？会上传到别处吗？

**全部存在你自己浏览器本地。** 除了你主动开启的云端备份，脚本不会把任何数据发到第三方服务器。详见下面的[数据与隐私](#数据与隐私)章节。

### 支持手机吗？

脚本**主要为电脑浏览器设计**。只优先保证大屏幕上的体验，目前只在少数地方做了窄屏适配（顶栏按钮会缩小、动态聚焦模式的缩放比例会调整），手机上的完整体验尚未专门打磨。

如果你主要用手机，建议暂时先在电脑上使用；手机上的油猴环境（如 Kiwi Browser、Via 等）能否正常运行，取决于该浏览器对脚本接口的支持程度，没有保证。
