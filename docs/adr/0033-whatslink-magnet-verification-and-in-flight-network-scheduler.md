# ADR-0033: Whatslink 磁力真实截图验车、全域在途 GET 请求单例去重与 CSP 事件捕获委托架构 (v7.6.3)

* **状态**: 已采纳 (Accepted)
* **日期**: 2026-11-13
* **关联版本**: `v7.6.3`
* **关联模块**: `WhatslinkVerifier`, `gmHttp`, `__gmGetInFlight`, `__gmGetMemo`, `setupImgFallbackDelegation`

---

## 1. 背景 (Context)

在 `v7.6.2` 稳定运行后，针对详情页磁力下载体验与全站基础网络/安全架构，暴露出了三类关键诉求与技术债务：

1. **磁力资源货不对板与缺乏真实截图验证**：
   * JAVDB 详情页汇聚了大量第三方发布的磁力链接，但由于 P2P 网络的匿名与不可控性，部分资源存在货不对板、虚假番号、内嵌垃圾广告或恶意伪装等问题。用户往往需耗费大量时间完成下载后才能确认片源真实性，亟需在下载前提供一种轻量、异步、零侵入的真实截图与文件明细校验手段。
2. **高频重复并发网络开销与连接池挤占 (Redundant In-Flight Network Requests)**：
   * 在瀑布流滚动加载、收藏夹批量扫描及详情页多模块并行渲染场景下，不同组件（如女优头像探测、跨域元数据查询、图床可用性探测）经常在数毫秒内对完全相同的静态 URL 发起多次并发 GET 请求。传统简单的结果缓存只能解决“请求完成后”的命中，无法解决“多个请求正在传输中（In-Flight）”时的网络栈冗余开销与连接阻塞。
3. **分散内联 `onerror` 的现代 CSP (Content Security Policy) 兼容风险**：
   * 既有代码中部分卡片与头像模板直接内联注入 `onerror="..."` 事件处理器。在现代浏览器日益严苛的 CSP 安全策略下，内联事件处理容易被浏览器拦截或触发控制台告警；同时分散在各模板的容错逻辑难以统一维护与容灾降级。

---

## 2. 决策与架构设计 (Decision)

### 2.1 Whatslink 磁力真实截图在线验车 (`WhatslinkVerifier`)
1. **Bulma 原生设计融合**：在详情页（无论是 Emby 沉浸式排版还是原生排版）磁力列表的「複製」「下載」按钮旁，按照官方 Bulma 风格无缝注入「在线验证」按钮（`button is-small is-info is-light`），保持视觉 100% 贴合官方。
2. **异步只读探测管道**：点击后通过 `gmHttp` 异步调用 Whatslink 公开接口（`https://whatslink.info/api/v1/link?url=`），解析真实资源标题、文件结构明细、视频格式、分辨率与清晰度截图。
3. **全屏走马灯灯箱预览体验**：
   * 支持多张截图全屏高画质轮播走马灯；
   * 提供底部缩略图悬停与快速点击导航；
   * 完整支持键盘快捷键交互（左/右箭头切图、Esc 退出、滚轮防穿透）；
   * 所有加载图片均强制标记 `referrerpolicy="no-referrer"`，规避跨域防盗链阻断。

### 2.2 全域在途 GET 请求单例合并调度与短期备忘 (`__gmGetInFlight` + `__gmGetMemo`)
1. **在途请求单例合并 (In-Flight Request Coalescing)**：
   * 在底层网络驱动 `gmHttp.request` 内部建立全局静态在途映射表 `__gmGetInFlight = new Map()`；
   * 仅针对安全的幂等 `GET` 请求，以规范化 URL 为键。当已有相同 URL 的请求处于在途传输中时，后续到达的并发调用不发起新的物理网络连接，而是将回调挂入已存在请求的等待队列中，共享同一个底层 Promise 与网络响应。
2. **短期安全内存备忘 (`__gmGetMemo`)**：
   * 响应成功后建立 5 分钟（`300,000ms`）短期内存备忘，防范极短时间内的突发抖动重试；
   * 严格排除任何非 GET 请求（POST/PUT/DELETE/OPTIONS）以及带有特定授权头的请求，保障有状态操作与数据突变的绝对原子性。

### 2.3 CSP 规范单点捕获阶段图片容错事件委托 (`setupImgFallbackDelegation`)
1. **全面肃清内联事件**：彻底清理 DOM 拼接模板中的内联 `onerror="..."` 属性，符合现代无内联脚本的 CSP 安全标准。
2. **单点捕获阶段事件委托**：
   * 仅在 `document` 根节点注册单例捕获阶段 `error` 事件监听器（`useCapture: true`）；
   * 采用统一的策略路由精准分发：对站点 Logo 降级、关于弹窗壁纸容错、女优官方头像失败转接 Gfriends 别名桥接，以及第三方图床防盗链路径自适应降级，实现全站图片容灾逻辑单点收敛。

---

## 3. 结果与权衡 (Consequences)

* **正向收益**：
  * 用户可在点击磁力下载前秒级预览片源真实截屏与文件明细，彻底终结“货不对板”的尴尬困扰；
  * 在途请求合并机制显著降低并发请求时的网络带宽消耗与连接建立开销，有效避免触发第三方图床/API 的 429 速率限制；
  * 全站消除内联 `onerror`，提高代码安全性并适配严格 CSP 环境。
* **边界与约束**：
  * Whatslink 为第三方公开服务，当目标磁力极为冷门或尚未被网络爬虫收录时，接口可能返回空结果，已在 UI 层设计了清晰的“暂无截图/数据未收录”友好占位提示。
