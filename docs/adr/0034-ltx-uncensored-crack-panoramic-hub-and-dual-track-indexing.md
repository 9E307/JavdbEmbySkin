# ADR-0034: LTX 破解影片全景多合一架构、双轨资源导流与赛博紫晶霓虹视觉重排系统 (v7.7.0)

* **状态**: 已采纳 (Accepted)
* **日期**: 2026-11-13
* **关联版本**: `v7.7.0`
* **关联模块**: `LtxIndexManager`, `LtxViewManager`, `VipCracker`, `JavdbThemeAdapter`, `WaterfallLayoutEngine`

---

## 1. 背景 (Context)

JAVDB 官方近期推出了 LTX（无码破解 / AI 还原高清流）分类与索引标签，但将此专区作为高级 VIP 会员专属权益进行了鉴权封锁。在脚本推进接入过程中，面临以下系统级与体验级挑战：

1. **服务端 302 重定向鉴权拦截难题**：
   * 官方主站将 `/?vft=6` 路由与 VIP 状态深度绑定。非会员访问该 URL 会直接触发服务端 HTTP 302 重定向跳转至会员订阅推广页，导致纯客户端常规 DOM 拦截与脚本注入完全落空，用户点击后被重定向甚至误入 TOP250 排行榜，无法获取有效影片数据。
2. **粗暴复刻导致的视觉割裂与交互崩塌**：
   * 外部参考脚本采用在右上角常驻注入突兀椭圆大按钮的方案，严重破坏了 JAVDB 官方设计语言与液态玻璃（Liquid Glass）毛玻璃视觉体系；
   * 专区常驻展开抢占了「每周推荐」原有的首屏焦点，破坏了主页既有的信息流层级；
   * 封面展示采用居中裁切，而 JAV 封套通常为宽幅（横纵比约 1.49:1），关键的女优面容与主标题均集中在右半版，居中裁切导致封面缺失有效主体信息。
3. **复杂多视图（错落瀑布流）重排计算失效**：
   * 脚本支持「经典网格」「紧凑列表」与「错落瀑布流（Masonry Waterfall）」三种视图。瀑布流视图依赖 JS 实时动态计算每张卡片的绝对坐标（`transform: translate3d`）。当用户激活 LTX 筛选时，简单的 CSS 隐藏无法驱动瀑布流重新计算列高，导致页面出现大量空白缺口甚至布局坍塌。
4. **资源索引割裂与双轨导流诉求**：
   * 官方站内标签体系（`c7=390`）收录规范但受限于站内爬虫时效；网络上同时存在专门收录 LTX 的第三方独立索引站（`https://ltx.libray.workers.dev/`），数据覆盖度更广。用户强烈需要在一个整合入口中无缝连接官方标签与全网第三方资源库。

---

## 2. 决策与架构设计 (Decision)

### 2.1 VIP 302 客户端安全拦截与双轨资源导流 (`VipCracker` & `LtxIndexManager`)
1. **智能路由守卫 (Client-Side Guarding)**：
   * 识别用户 VIP 破解功能启用状态。当 VIP 破解处于激活状态时，全面接管并拦截官方 `/?vft=6` 筛选按钮的跳转行为，将其转化为当前信息流的瞬时 LTX 过滤开关；
   * 若用户主动关闭 VIP 破解，则忠实回退为官方原生链接跳转，由 JAVDB 服务端根据账号真实权益决定响应。
2. **双轨资源互联 (Dual-Track Resource Routing)**：
   * **本站 LTX 专区**：一键直达官方深度收录标签库 `/tags?c7=390`；
   * **外部 LTX 资源库**：在精选控制条后增设独立外链按钮直达 `https://ltx.libray.workers.dev/`，引入与 GitHub Star 赞助按钮同款的 `@keyframes ghGlowing` 霓虹彩虹光影边框流动动画与液态玻璃悬浮微光提示，打通全网海量第三方 LTX 片源。

### 2.2 全景多合一架构与折叠精选横轨 (`LtxViewManager`)
1. **首屏层级与折叠状态持久化**：
   * 将「LTX 破解精选」横向流式轨道规范锚定在「每周推荐」正下方；
   * 专区默认支持独立折叠/展开，展开状态持久化存储于 `GM_setValue`；
   * 调整主页视觉权重：每周推荐封面尺寸扩充至 `300px`，LTX 精选封面规格统一定为 `260px`，层次分明。
2. **横版封套右侧精准取景 (Right-Side Cover Cropping)**：
   * 针对 2:3 纵向海报卡片，放弃统一的居中裁切；
   * 采用绝对定位右贴齐取景算法：`width: 200%; height: 100%; right: 0; object-position: right center;`，完美聚焦右半幅女优写真与片名主体，彻底杜绝黑边与形变。
3. **液态玻璃主题皮肤完全同步**：
   * 控制条宽度与「每周推荐」100% 精确对齐；
   * 工具条全面融入 `JavdbThemeAdapter`，统一注入毛玻璃滤镜（`backdrop-filter: blur(12px)`）、半透高亮底色与微距阴影，消除视觉割裂。

### 2.3 赛博紫晶霓虹 (Cyber Violet) 视觉系统与微光呼吸边框
1. **紫晶霓虹角标前置规范**：
   * 摒弃突兀的右上角大徽章，设计赛博紫晶霓虹微章（`linear-gradient(135deg, #a855f7 0%, #ec4899 100%)`）；
   * 角标统一放置于卡片左下角，严格排列在「无码破解」「中文字幕」等标签序列最前方，保持卡片元数据读取流的统一。
2. **非侵入式微距悬停边框 (Hover-Only Thin Outline)**：
   * 废除常驻亮起的粗边框设计；
   * 筛选激活后，卡片平时保持通透干净；仅在用户鼠标悬停时，动态激活动画过渡的 `1px` 紫晶微光轮廓（`border: 1px solid rgba(168, 85, 247, 0.45); box-shadow: 0 0 12px rgba(168, 85, 247, 0.25)`），优雅而克制。
3. **主页与收藏夹独立控制台**：
   * 主页与收藏夹的 LTX 筛选状态彼此独立解耦；
   * 收藏夹工具栏挂载专属筛选开关，满足用户在个人资产库与公共信息流中的差异化检索意图。

### 2.4 错落瀑布流自适应重排协调 (`WaterfallLayoutEngine Coordination`)
1. **视图层穿透与排版联动**：
   * 修复传统 CSS 隐藏规则被瀑布流 `display: block !important` 强行覆盖的问题；
   * 建立筛选与排版引擎的双向事件总线：当 LTX 筛选状态切换时，主动唤醒瀑布流排版计算管道，重构过滤后的 `visibleItems` 集合，重新计算各列累加高度与 `translate3d(x, y, 0)` 偏移，消除布局空隙与折叠残影。

## 3. 结果与权衡 (Consequences)

* **正向收益**：
  * 彻底攻克 JAVDB 官方对 LTX 路由的 VIP 302 服务端跳转限制，实现了平滑无感的客户端筛选重排；
  * 构建了极具质感的赛博紫晶霓虹视觉体系，不仅与官方设计无缝融合，更为液态玻璃主题增添了现代化科技感；
  * 右侧取景裁剪算法大幅提升了封面浏览的有效信息获取率与视觉冲击力；
  * 双轨资源导流打通了官方标签与全网第三方资源库，极大拓宽了用户找片场景。
* **边界与约束**：
  * 外部 LTX 资源库系第三方部署的 Cloudflare Worker 站点，其可用性依赖第三方网络环境；脚本通过清晰的浮窗提示（“第三方收集站点，数据更全”）明确告知用户来源边界。
